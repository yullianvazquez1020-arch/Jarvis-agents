## Cómo se vende

1. Anuncio: 45 segundos, mudo, del archivo `02-jarvis-negocio.mp4`, cortado antes del minuto 1:30. No usar el tramo de las galletas («costs only $1») ni el señor de los diplomas.
2. Clase: quien pagó recibe la grabación de las láminas y una hoja de una página.
3. Llamada: día 2, cuatro minutos, ¿hiciste la hoja? Día 7, seis minutos, se ofrece la pieza que quedó fuera. Un no se respeta.

Texto del anuncio, sin precio de un dólar:

```

Prepara. Tú apruebas.
Taller online, sin inventario.
```
